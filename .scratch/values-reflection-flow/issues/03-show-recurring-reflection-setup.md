# 03: Show recurring-reflection setup on Completed

**What to build:** A participant can find and use recurring-reflection setup directly on the completed page, choose a
supported service and review or copy their prompt.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Display **Set up recurring reflection** as a heading with service choices, the selected service's instructions and
      the copy action visible without expanding an outer panel.
- [x] Preserve the radio choices for Microsoft 365 Copilot, Claude Cowork and Codex, and show instructions corresponding
      to the selected service.
- [x] Keep optional context and the full prompt preview individually expandable, and include saved notes or reasons only
      when the participant selects them.
- [x] Copy the composed prompt with clear success or failure feedback; the app itself does not schedule or send it.
- [x] Preserve existing completed-page actions and verify the setup on relevant screen sizes and with keyboard
      navigation. The separate behaviour-reflection feature flag must not hide this setup.
