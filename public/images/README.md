This directory contains public images used in the application.

`core-values-growth.svg` is the home choice-screen backdrop. `core-values-values.svg` appears when values setup is open and through its exercise flow; `core-values-behaviour.svg` appears through behaviour reflection. Their branching forms and leaves derive from `core-values.png` and use the plum, rose, and warm neutral palette from `src/styles/palette.css`.
`core-values-about.svg` frames the About page with branching paths that suggest revisiting a chosen direction. `core-values-contact.svg` uses gently converging paths and a small heart-and-sprout mark to suggest an open conversation. Both use the same low-contrast edge framing and palette as the other page backgrounds.

Best practices:
1. Use descriptive names for images
2. Use lowercase with hyphens for filenames (e.g., core-values-logo.png)
3. Include image optimization where possible
4. Consider using Next.js Image component for automatic optimization
